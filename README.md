ChewTune咀嚼检测


ChewTune 是一款面向真实用餐场景的咀嚼习惯训练移动应用，旨在帮助用户感知并改善进食过程中的咀嚼节奏、咀嚼频率与左右侧使用习惯。随着学习和工作节奏加快，许多人习惯一边看手机、办公或思考其他事情一边吃饭，进食过程逐渐变得无意识，容易出现咀嚼过快、咀嚼不足、长期偏侧咀嚼等问题。这些行为虽然细微，却会影响进食体验、饱腹感感知、口腔肌肉使用和长期健康习惯。

不同于传统饮食健康 App 主要关注热量记录、营养摄入或餐后复盘，ChewTune 将关注点前移到“正在发生的进食过程”。系统通过佩戴于耳部/面部附近的可穿戴传感器采集咀嚼时产生的细微运动信号，并利用实时识别算法判断用户是否处于咀嚼状态，进一步计算咀嚼频率、节奏稳定性和左右侧咀嚼倾向。App 作为用户主要交互入口，负责完成餐前个性化设置、用餐中状态反馈和餐后数据报告，将底层传感与算法结果转化为用户能够理解和调整的健康行为反馈。

ChewTune 的核心创新在于采用音乐化、非打断式的干预方式。当系统检测到咀嚼过快、节奏不稳定或长期偏侧使用时，不通过强提醒、警告或打断式弹窗干预用户，而是通过音乐节奏、声场位置和声音层次的变化，引导用户自然感知自己的进食状态。例如，当用户长时间偏向一侧咀嚼时，音乐声场会随之偏移，提示用户调整咀嚼侧；当咀嚼节奏过快时，音乐节奏会引导用户逐步放慢。这样的反馈方式降低了健康管理的压力感，也更适合在真实用餐场景中长期使用。

在移动端界面设计上，ChewTune 以“餐前设置—用餐反馈—餐后复盘—长期习惯追踪”为主要流程，构建轻量、清晰、可持续的使用体验。用户在餐前可通过 App 选择音乐偏好、设置检测目标，并根据引导完成设备佩戴；用餐过程中，App 以简洁状态页呈现咀嚼节奏、左右侧平衡和反馈变化，避免复杂操作干扰进食；餐后则通过图表、热力图和总结卡片，将原本难以觉察的身体行为转化为清晰可理解的习惯记录。用户还可以根据自身进食习惯调整检测灵敏度和提醒频率，使系统更贴合不同人群的真实需求。

ChewTune 适用于有体重管理、面部外形改善、口腔健康维护需求的人群，也适合长期分心进食、希望提升进食觉察的学生和职场人。作品尝试将移动应用、可穿戴感知与音乐交互结合起来，为饮食健康管理提供一种更温和、更日常、更易坚持的新方式。
